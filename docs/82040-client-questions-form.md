# HSMV 82040 — Client Questions (fill-in version)

The same eight questions as `docs/82040-client-questions-email.md`, laid out so the
client answers inside the document instead of writing an email back.

This is the version to use. `docs/82040-client-questions.html` is a fillable page
built for the same job; it was not adopted, because pasting into a Google Doc is
fewer moving parts than sending an attachment back and forth.

HOW TO USE THIS
1. Open a blank Google Doc.
2. Copy everything below the line and paste it in.
3. Share with edit access. They tick a box or type on the answer line.

Written deliberately in plain text — no markdown bold or heading marks — so it looks
the same whether or not Google Docs interprets the paste as markdown. The ☐
characters paste as normal text and can be typed over with ☑ or an X.

Status: drafted 11 Aug 2026, not yet sent.
Answers land back in the "Ambiguous — confirm before mapping" section of
`docs/82040-coverage.md`.
